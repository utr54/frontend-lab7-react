# Лабораторна робота №7 — React

## Локальний запуск

Потрібні **Node.js 22** та **npm**. У терміналі відкрийте папку проєкту та виконайте:

```bash
npm ci
npm start
```

Відкрийте адресу, яку покаже термінал (зазвичай http://localhost:3000/frontend-lab7-react/). Для зупинки сервера натисніть `Ctrl+C`.
